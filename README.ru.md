# SmartHorde — Чтобы мобы больше не «стояли и молча получали»

[简体中文](README.md) | [English](README.en.md) | [Русский](README.ru.md)

**Мобы больше не «стоят и молча получают удары» — теперь они думают, взаимодействуют, лазают по стенам, уклоняются и обходят вас с флангов, как настоящие враги.**

SmartHorde — мод улучшения ИИ мобов для Minecraft 1.21.1 (NeoForge). Он наделяет зомбиподобных мобов полноценной боевой системой ИИ (атака, защита, маневрирование), а также добавляет систему волн орды, битвы с боссами и уровни сложности.

## Основные возможности

### Умный зомби (SmartZombie)

Зомби с полноценным тактическим ИИ, способный на:

- **Комбинированные атаки**: четыре приёма — лёгкий удар, размах, тяжёлый удар и выпад — каждый со своей подготовкой (замахом), дальностью, углом сектора и перезарядкой
- **Обход с флангов**: при лобовом столкновении перемещается к вашим бокам и спине, вынуждая поворачиваться или открывать спину
- **Контроль дистанции**: при слишком близком расстоянии отходит на комфортную дистанцию перед атакой; при «кайтинге» срезает по диагонали, а не бежит по прямой
- **Разделение**: несколько мобов не слипаются в одну точку — они расходятся, образуя кольцо окружения
- **Лазание по стенам**: лазание в стиле паука по любой стене (до 6 блоков; один моб способен перелезть самостоятельно), деревянные двери открывает автоматически
- **Уклонения по трём источникам**: уклонение после получения урона, прыжок в сторону при прицеливании из лука, прыжок в сторону, когда ваш прицел наведён прямо на моба (в упор в ближнем бою тоже срабатывает), рывок-уклонение при обнаружении летящей стрелы (у каждого уклонения есть перезарядка)
- **Умный выбор цели**: приоритет ближайшему игроку с наименьшим здоровьем и без брони

### Улучшение ванильных зомби (включено по умолчанию)

Работает сразу после установки — все естественно спавнящиеся ванильные зомби автоматически получают описанный выше тактический ИИ, без дополнительной настройки. При первой инъекции в лог выводится `[SmartHorde] Vanilla zombie enhanced...` для подтверждения.

### Система волн орды

Одна команда — и начинается тест на выживание:

- `/smarthorde wave start 5` запускает орду из 5 волн
- Нарастающие волны: 1-я волна — 7 мобов, 2-я — 10, 3-я — 13... чем дальше, тем больше
- Кольцевой спавн: мобы появляются кольцом в 24–32 блоках вокруг вас — не застревают в стенах и не висят в воздухе
- Между волнами 5 секунд на подготовку с живым обратным отсчётом в чате
- За зачищенную волну — изумруды + опыт; за прохождение всех волн — главный приз, алмазы
- HUD вверху экрана в реальном времени показывает прогресс волн, число выживших и статус фазы

### Босс: Повелитель орды

- 200 HP / 10 урона / 0.8 сопротивления отбрасыванию / 8 брони
- Автоматический переход в следующую фазу при 75%/50%/25% здоровья (цвет полосы: белый → синий → фиолетовый → красный)
- Каждая фаза: +25% скорости атаки и ускорение передвижения
- При смене фазы призывает мини-орды прислужников (6/8/10 мобов)
- `/smarthorde summon-boss` — призыв (без аргумента — случайный вариант: Громила / Чумной / Морозный / Инфернальный)

### Четыре уровня сложности

| Сложность | Здоровье | Урон | Скорость | Скорость атаки | Перезарядка уклонения |
|------|------|------|------|------|----------|
| Easy | ×0.75 | ×0.70 | ×0.90 | ×0.75 | 2.25s |
| Normal | ×1.00 | ×1.00 | ×1.00 | ×1.00 | 1.5s |
| Hard | ×1.35 | ×1.25 | ×1.10 | ×1.25 | 1.1s |
| Nightmare | ×1.75 | ×1.50 | ×1.25 | ×1.50 | 0.7s |

Переключение: `/smarthorde difficulty nightmare`; изменения в `smarthorde-server.toml` перезагружаются на лету через встроенный файловый монитор NeoForge.

## Звуки и эффекты

- Замах перед атакой: утробный рык + хруст костей
- Уклонение: резкий вдох и остановка
- Приближение орды: учащающееся сердцебиение + диссонирующий боевой рог с малой секундой + нарастающий шёпот + жуткое высокочастотное глиссандо
- Ярость босса: грохот + рык с падающим тоном + металлический визг + инфразвуковой шлейф
- Волна зачищена: затухающий похоронный колокол + отступающий ледяной ветер
- Полоса здоровья над головой: у раненых мобов отображается градиентная полоса зелёный→красный, при полном здоровье скрыта

Все эффекты и звуки можно включать/выключать отдельно в конфигурации.

## Список команд

| Команда | Описание |
|------|------|
| `/smarthorde difficulty [preset]` | Сменить сложность (easy/normal/hard/nightmare) |
| `/smarthorde summon [count]` | Призвать указанное число SmartZombie вручную |
| `/smarthorde summon-boss [variant]` | Призвать Повелителя орды (brute/plague/frost/inferno) |
| `/smarthorde wave start [waves]` | Запустить орду с указанным числом волн |
| `/smarthorde wave stop` | Остановить текущую орду |
| `/smarthorde wave info` | Показать информацию о текущей волне |
| `/smarthorde top` | Таблица лидеров орды (игроки онлайн) |
| `/smarthorde stats` | Личная боевая статистика |

## Конфигурация

Файл конфигурации: `config/smarthorde-server.toml`. Основные опции:

| Опция | По умолчанию | Описание |
|--------|--------|------|
| `inject.vanillaMobs` | true | Улучшать ванильных зомби (включено по умолчанию) |
| `difficulty.preset` | normal | Пресет сложности |
| `boss.enabled` | true | Разрешить призыв босса |
| `boss.phaseThresholds` | [0.75, 0.5, 0.25] | Пороги смены фаз |
| `horde.baseCount` | 7 | Число мобов в первой волне |
| `horde.countPerWave` | 3 | Прирост с каждой волной |
| `effects.particlesEnabled` | true | Вкл/выкл частицы |
| `effects.soundsEnabled` | true | Вкл/выкл звуки |
| `effects.headHealthBar` | true | Вкл/выкл полосу здоровья над головой |
| `performance.auditEnabled` | false | Журнал аудита производительности (выключен) |

## Устранение неполадок

Если естественный спавн не работает, проверьте по порядку:

1. **Сложность не должна быть Peaceful** — в мирном режиме мобы не спавнятся
2. **Уровень освещённости должен быть ≤ 7** — SmartZombie появляются только ночью или в темноте (пещеры, помещения)
3. **Лимит MONSTER не должен быть исчерпан** — если рядом уже много мобов, новые не появятся
4. **Удалите Sodium** — у Sodium есть проблемы совместимости с отрисовкой некоторых сущностей
5. **Сначала проверьте командой** — выполните `/smarthorde summon 5` и нажмите F3+B, чтобы увидеть хитбоксы и исключить проблемы правил спавна

### Зависание на раннем окне при запуске с ошибкой "Timed out trying to setup the Game Window"?

Это таймаут создания OpenGL-контекста ранним окном NeoForge на старых драйверах видеокарт (особенно часто на встроенной графике вроде Intel HD 2000/2500 с поддержкой только GL 4.0) — к моду отношения не имеет. Решается в два шага:

1. Удалите моды семейства Sodium (они внедряются на этапе загрузки и плохо совместимы со старым GL-железом);
2. Отредактируйте `config/fml.toml` в каталоге экземпляра игры, изменив `earlyWindowControl = true` на `false`, чтобы пропустить раннее окно и позволить игре самой создать окно.

## Принципы проектирования

- **Ноль манипуляций с блоками**: ничего не ломает и не ставит, не загрязняет мир
- **Управление конфигурацией**: практически все значения и поведение настраиваются в конфиге
- **Производительность прежде всего**: каждый AI Goal имеет троттлинг по перезарядке, число частиц ограничено, TPS ≥ 18 при 40 мобах на экране
- **Пошаговое улучшение**: у каждого модуля свой переключатель — можно использовать только часть функций
- **Работает из коробки**: настройка по умолчанию открывает все ключевые функции без ручной доводки

## Совместимость

- Minecraft 1.21.1
- NeoForge 21.1.x
- Полная совместимость с ванильными зомби (инъекция улучшений, а не замена)
- Не изменяет ни один ванильный блок или предмет

## Разработка и сборка

```bash
# Требуется JDK 21; в репозитории нет gradle wrapper — сначала установите Gradle 8.9+
gradle wrapper --gradle-version 8.9
./gradlew build          # результат: build/libs/smarthorde-<version>.jar
python tools/gen_assets.py   # опционально: перегенерировать звуки/текстуры (pip install soundfile pillow numpy)
```
