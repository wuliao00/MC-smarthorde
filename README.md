# SmartHorde —— 让怪物不再"傻站着挨打"

[简体中文](README.md) | [English](README.en.md) | [Русский](README.ru.md)

**让怪物不再"傻站着挨打"，而是像真正的敌人一样思考、协作、翻墙、闪避、包抄你。**

SmartHorde 是一个面向 Minecraft 1.21.1（NeoForge）的怪物 AI 增强模组。它为僵尸类怪物注入了一套完整的攻防走位 AI 体系，并提供了尸潮波次系统、Boss 战和难度分级。

## 核心特性

### 智能僵尸与五大战术兵种（SmartZombie）

一只拥有独立多部件立体 3D 建模（`128×128`）、黑夜全亮度自发光图层与接地防穿模骨骼动画的战术僵尸：

- **定制立体 3D 建模与发光图层**：告别原版 6 方块火柴盒——内置深陷眉弓、护腕与腰封，四大精英各具专属 3D 几何部件（镂空刺客兜帽与双袖刃、条顿铁血面罩与重装肩甲、双弯骨角与背脊骨刺、鎏金锯齿战冠+百夫长横羽+动态飘动披风）及夜间发光瞳孔/符文
- **接地防穿模骨骼关键帧引擎**：轻击、重击、横扫、突刺四式招式拥有独立的 60fps 正序蓄力挥砍动画，搭配贴墙攀爬、侧跃闪避、举盾推进与战吼姿态；上身弯腰自然下沉而双脚锁死接地不浮空，副手持盾自动防过顶穿颅
- **五大战术兵种分化**：
  - **智能僵尸（`standard`）**：均衡型战术主力，佩戴立体镂空战术头箍+发光侦测镜、左肩轻甲与背囊
  - **疾风突袭者（`raider`）**：高移速、短闪避冷却，积极向侧翼薄弱处包抄突刺
  - **重装先锋（`vanguard`）**：高甲高血，副手持盾稳步推进格挡正面箭矢与近战（玩家可用斧头劈砍触发 5 秒破盾硬直）
  - **狂血战鬼（`berserker`）**：半血以下进入嗜血狂暴，移速与出招频率大幅提升
  - **尸潮百夫长（`commander`）**：小队统领，周期性发出震天战吼赋予周围友军迅捷与力量增益
- **双翼合围与面向走位**：自动统计玩家左右两侧友军密度并包抄空虚侧；后撤与散开全程采用面向目标的战术垫步（`strafe`），杜绝背身扭头穿模
- **软排斥防叠模**：贴身混战时多只怪平滑散开形成包围圈，绝不重叠卡进同一坐标
- **翻墙与开门系统**：贴墙交替攀爬高墙（上限 6 格，墙顶自动跨步登顶），遇到关闭木门自动推开
- **地形净空四源闪避**：受击后闪避、被远程武器瞄准时侧跳、中近距被准星锁定时侧跳、来袭箭矢侧扑，自动探测墙体与悬崖净空防止撞墙跳崖
- **智能选目标与友军呼救**：优先锁定最近、残血、低护甲的玩家，受击时呼叫周围友军协同围攻

### 原版僵尸增强（默认开启）

安装即用——所有自然生成的原版僵尸自动获得上述战术 AI，无需额外配置。首次注入时日志会输出 `[SmartHorde] Vanilla zombie enhanced...` 确认生效。

### 尸潮波次系统

一键开启生存压力测试：

- `/smarthorde wave start 5` 启动 5 波尸潮（无管理员权限的生存玩家也可合成或从领主战利品获取**智潮战号 `smarthorde:horde_horn`**，长按右键吹响直接开启试炼，潜行+右键查询波次进度；创造模式另提供两种实体刷怪蛋）
- 波次递进：第 1 波 7 只，第 2 波 10 只，第 3 波 13 只……越往后越多
- 环形安全生成与防逃课机制：怪物在你周围 24~32 格环形区域刷出，排除液体与危险方块并校验碰撞净空；尸潮期间阵亡或远离战场超过 144 格将判定试炼失败并自动清理残怪
- 决战里程碑波：每满 5 波（或 5+ 波最终决战波）自动伴随一位尸潮领主参战
- 每波之间有 5 秒准备时间，屏幕顶部 HUD 实时显示波内清剿进度条、波次刻度与存活数（自动避让活跃 BossBar）
- **专属战术反制装备**（生存可由绿宝石 + 钻石锻造）：
  - **智潮战术头盔（`smarthorde:smart_helmet`）**：独立 3D 绿宝石目镜重盔外观，减免 **15%** 智尸/领主伤害，并周期性扫描高亮 16 格内绕后突袭者与墙后伏兵
  - **智潮破阵之刃（`smarthorde:smart_sword`）**：对四大精英智尸与尸潮领主造成 **+25%** 破阵伤害，并可直接击溃重装先锋的正面盾防 3.5 秒

### Boss：尸潮领主

- 200 血量 / 10 伤害 / 0.8 击退抗性 / 10 护甲，采用独立 `128×128` 倒三角泰坦巨兽 3D 骨架（宽肩粉碎铁拳套、发光肋骨炉心、**可动怒吼下颚**与四变体独立王冠/巨角/脉动孢囊/熔岩魔角）
- 四大变体专属主动战技（均带 16 tick 蓄力前摇预警，零方块破坏）：
  - **蛮横（`brute`）**：震地咆哮 —— 猛砸地面释放冲击环，起跳离地可规避半数伤害
  - **瘟疫（`plague`）**：疫毒迷雾 —— 扩散剧毒孢子环使周围玩家中毒虚弱，并加速友军仆从
  - **寒霜（`frost`）**：凛冬霜环 —— 释放极寒霜环叠加细雪冻伤与迟缓
  - **炼狱（`inferno`）**：烈焰新星 —— 引爆周身烈焰点燃并震退近身玩家
- 血量降至 75%/50%/25% 时自动进入下一阶段（血条颜色随变体演进），攻速与移速提升并召唤仆从
- `/smarthorde summon-boss` 安全地面召唤（自动搜寻无阻挡地表，可指定 `brute`/`plague`/`frost`/`inferno`）

### 四档难度

| 难度 | 生命 | 伤害 | 速度 | 攻速 | 闪避冷却 |
|------|------|------|------|------|----------|
| Easy | ×0.75 | ×0.70 | ×0.90 | ×0.75 | 2.25s |
| Normal | ×1.00 | ×1.00 | ×1.00 | ×1.00 | 1.5s |
| Hard | ×1.35 | ×1.25 | ×1.10 | ×1.25 | 1.1s |
| Nightmare | ×1.75 | ×1.50 | ×1.25 | ×1.50 | 0.7s |

`/smarthorde difficulty nightmare` 切换；修改 `smarthorde-server.toml` 后由 NeoForge 内建文件监视器热重载。

## 音效与特效

- 攻击前摇：喉音咆哮 + 骨裂脆响
- 闪避：倒吸凉气骤停
- 尸潮来袭：心跳渐密 + 小二度不协和战号 + 耳语声浪 + 高频诡异滑音
- Boss 狂暴：轰击 + 音调坠落的低吼 + 金属尖啸 + 次声尾巴
- 清波：丧钟余韵 + 寒风退散
- 头顶血量条：打残的怪头顶显示绿→红渐变血条，满血隐藏

全部特效和音效可通过配置独立开关。

## 命令一览

| 命令 | 说明 |
|------|------|
| `/smarthorde difficulty [preset]` | 切换难度（easy/normal/hard/nightmare） |
| `/smarthorde summon [count] [role]` | 召唤指定数量与兵种的智尸（standard/raider/vanguard/berserker/commander/random） |
| `/smarthorde summon-boss [variant]` | 在安全地面召唤尸潮领主（可指定 brute/plague/frost/inferno） |
| `/smarthorde wave start [waves]` | 启动指定波数的尸潮 |
| `/smarthorde wave stop` | 终止当前尸潮并清理波次残怪 |
| `/smarthorde wave skip` | 跳过当前倒计时或波次阶段 |
| `/smarthorde wave info` | 查看当前波次信息 |
| `/smarthorde clear` | 一键清理当前维度所有智能僵尸与尸潮领主 |
| `/smarthorde status` | 查看当前难度、维度智尸/精英/领主存活数与活跃波次概览 |
| `/smarthorde top` | 尸潮排行榜（在线玩家） |
| `/smarthorde stats` | 个人战绩统计（含精英与 Boss 击杀） |

## 配置

配置文件位于 `config/smarthorde-server.toml`，主要选项：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `inject.vanillaMobs` | true | 增强原版僵尸（默认开启，开箱即用） |
| `difficulty.preset` | normal | 难度预设 |
| `boss.enabled` | true | 允许 Boss 召唤 |
| `boss.abilitiesEnabled` | true | 启用 Boss 四变体专属主动战技 |
| `boss.phaseThresholds` | [0.75, 0.5, 0.25] | 阶段切换阈值 |
| `horde.baseCount` | 7 | 首波怪物数量 |
| `horde.countPerWave` | 3 | 每波递增数量 |
| `horde.eliteChance` | 0.35 | 精英战术兵种基础出现概率 |
| `horde.eliteEquipment` | true | 精英兵种佩戴零掉落战术装备（如重装先锋持盾） |
| `horde.bossOnMilestoneWave` | true | 每满 5 波或决战波伴随尸潮领主参战 |
| `effects.particlesEnabled` | true | 粒子特效开关 |
| `effects.soundsEnabled` | true | 音效开关 |
| `effects.headHealthBar` | true | 头顶血量条开关 |
| `performance.auditEnabled` | false | 性能审计日志（默认关闭） |

## 故障排查

如果自然生成不生效，请依次检查：

1. **难度不能是和平模式**——和平模式下怪物不会生成
2. **亮度必须 ≤ 7**——SmartZombie 只在夜晚或黑暗处生成（洞穴、室内）
3. **MONSTER 上限未被占满**——如果周围已有大量怪物，新怪物不会刷出
4. **移除 Sodium**——Sodium 与部分实体渲染存在兼容性问题
5. **先用命令验证**——执行 `/smarthorde summon 5`，按 F3+B 查看碰撞箱，排除生成规则问题

### 启动时卡在早期窗口并报 "Timed out trying to setup the Game Window"？

这是 NeoForge 早期显示窗口在老旧显卡驱动上创建 OpenGL 上下文超时（Intel HD 2000/2500 等仅支持 GL 4.0 的核显尤其常见），与本模组无关。两步解决：

1. 移除 Sodium 系模组（它们挂载在启动引导阶段且对老 GL 硬件不友好）；
2. 编辑实例目录下 `config/fml.toml`，把 `earlyWindowControl = true` 改为 `false`，跳过早期显示窗口，由游戏本体正常创建窗口。

## 设计原则

- **零方块操作**：全程不破坏/不放置任何方块，不污染世界
- **配置驱动**：几乎所有数值和行为都可通过配置文件调整
- **性能优先**：所有 AI Goal 有冷却节流，粒子数量封顶，40 只同屏 TPS ≥ 18
- **渐进增强**：每个功能模块独立开关，可以只用其中一部分
- **开箱即用**：默认配置即可体验全部核心功能，无需手动调整

## 兼容性

- Minecraft 1.21.1
- NeoForge 21.1.x
- 与原版僵尸完全兼容（注入增强而非替换）
- 不修改任何原版方块或物品

## 开发与构建

```bash
# 需要 JDK 21；仓库不含 gradle wrapper，先安装 Gradle 8.9+
gradle wrapper --gradle-version 8.9
./gradlew build          # 产物 build/libs/smarthorde-<version>.jar
python tools/gen_assets.py   # 可选：重新生成音效/贴图（pip install soundfile pillow numpy）
```
